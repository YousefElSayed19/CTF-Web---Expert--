# Web CTF Project Structure

## Folder Structure

```text
3- Web/
├── Main Work/
└── Web CTF Full/
```

## Folder Purpose

### `Main Work/` — Working Directory

The main working folder for active development and ongoing changes.

- Use this folder for day-to-day work.
- This is the active development copy.

### `Web CTF Full/` — Final Task Submission

The complete task submission folder, containing all required deliverables and related files.

- Use this folder as the packaged submission copy.
- Keep the files needed to review or run the submitted task here.

## Important Note

`Main Work/` is the active working copy, while `Web CTF Full/` is the complete task submission. Keep this distinction clear when editing, organizing, or sharing project files.
